# رابط کاربری پروتکل نیروست

یک رابط کاربری وب مدرن با محوریت انرژی برای پروتکل نیروست - یک سیستم تسویه‌حساب انرژی و محاسبات مبتنی بر بازار.

## امکانات

- **داشبورد انرژی**: نمای کلی بلادرنگ همراه با نمودارهای تولید/مصرف و متریک‌های بازار
- **بازار انرژی**: نمایش دفتر سفارش، ثبت پیشنهاد خرید/فروش، مشاهدهٔ حراج‌های فعال
- **رجیستری پنل**: مدیریت پنل‌های خورشیدی، مشاهدهٔ داده‌های تولید، ثبت پنل جدید
- **کیف پول انرژی**: مشاهدهٔ موجودی، انتقال توکن، پیگیری تراکنش‌ها
- **موتور تسویه**: نظارت بر وضعیت تسویه، مشاهدهٔ موقعیت‌های مالی
- **خزانهٔ استیکینگ**: مدیریت توکن‌های استیک‌شده، واریز/برداشت، مشاهدهٔ جریمه‌ها
- **حاکمیت DAO**: ایجاد پیشنهاد، رأی‌گیری روی تصمیمات پروتکل
- **یکپارچگی Web3**: اتصال به MetaMask یا سایر کیف‌پول‌های Web3

## طراحی

رابط کاربری با طراحی موضوع‌محور انرژی شامل موارد زیر است:
- تم تیره بهینه‌شده برای داشبوردهای انرژی
- طرح رنگی سبز/آبی نمایانگر انرژی تجدیدپذیر
- نمودارها و تجسم‌های بلادرنگ
- چیدمان واکنش‌گرا برای همهٔ اندازه‌های صفحه‌نمایش

## شروع کار

### پیش‌نیازها

- Node.js نسخهٔ ۱۸ به بالا و npm/yarn
- MetaMask یا کیف پول سازگار با Web3 (برای تعامل با بلاک‌چین)

### نصب

```bash
cd ui
npm install
```

### توسعه

```bash
npm run dev
```

اپلیکیشن روی `http://localhost:3000` باز می‌شود.

### بیلد

```bash
npm run build
```

### پیش‌نمایش نسخهٔ نهایی

```bash
npm run preview
```

## ساختار پروژه

```
ui/
├── src/
│   ├── components/
│   │   ├── views/          # کامپوننت‌های اصلی نما
│   │   ├── Header.jsx      # منوی ناوبری بالا
│   │   ├── Sidebar.jsx     # منوی ناوبری کناری
│   │   └── Dashboard.jsx   # روتر اصلی
│   ├── context/
│   │   └── Web3Context.jsx  # اتصال کیف پول Web3
│   ├── App.jsx             # کامپوننت ریشه
│   ├── main.jsx            # نقطهٔ ورود
│   └── index.css           # استایل‌های عمومی
├── index.html
├── package.json
└── vite.config.js
```

## اتصال قرارداد

برای اتصال به قراردادهای مستقرشده، آدرس قراردادها را در نمای تنظیمات به‌روزرسانی کنید یا آن‌ها را در Web3Context پیکربندی کنید.
